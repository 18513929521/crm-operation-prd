## 1. 需求背景

### 1.1 业务背景

NovoGrowth是一款面向企业的SaaS产品，需要一个配套的运营平台来管理租户、配置应用功能、控制租户授权。当前面临以下问题：

**现状与痛点**：
- 缺少统一的租户管理后台
- 无法灵活配置NovoGrowth的菜单和权限
- 租户授权流程不清晰
- 运营人员无法高效管理租户账号

**业务发展需要**：
- 快速上线MVP版本验证商业模式
- 支持租户的全生命周期管理
- 实现NovoGrowth应用的统一配置
- 建立运营平台与NovoGrowth的数据同步机制

### 1.2 用户角色

| 角色名称 | 角色描述 | 使用场景 |
|----------|----------|----------|
| 超级管理员 | 运营平台最高权限管理员 | 管理运营人员、配置应用、管理所有租户 |
| 运营人员 | 负责日常租户运营工作 | 创建租户、查看租户信息、处理租户问题 |
| 租户管理员 | NovoGrowth租户的主账号 | 使用NovoGrowth平台功能 |

### 1.3 需求来源

- **来源**：产品规划 + 商业需求
- **优先级**：P0-紧急（MVP核心功能）
- **预期上线时间**：2025-11-01

## 2. 需求目标

### 2.1 核心目标

1. **快速验证商业模式**：在2周内完成MVP开发并上线
2. **统一应用配置管理**：为NovoGrowth提供统一的菜单和权限配置
3. **高效租户管理**：支持租户创建和自动授权，简化操作流程
4. **稳定数据同步**：确保运营平台与NovoGrowth的数据一致性

### 2.2 MVP范围

**包含的核心功能**：

1. **系统管理应用**
   - ✅ 运营人员管理（增删改查）
   - ✅ 登录认证功能

2. **应用管理应用** ⭐ 核心
   - ✅ 应用中心
     - ✅ 应用授权（应用模块配置）
     - ✅ 菜单按钮配置（界面化管理菜单和按钮）
     - ✅ 操作权限配置（界面化管理操作权限）
     - ❌ 数据权限配置（V1.1版本）

3. **租户管理**
   - ✅ 租户列表和创建
   - ✅ 新增租户自动授权所有应用
   - ✅ 授权配置自动推送到NovoGrowth

**不包含的功能**：
- ❌ 套餐管理（V1.1版本）

- ❌ 操作日志审计（V1.1版本）
- ❌ 数据统计和报表（V2.0版本）

#### 操作：新增用户

**原型图**：
![新增用户界面](./原型图/用户管理/新增用户@1x.png)

**功能需求**：

1. **页面入口**
   - 位置：用户列表页面
   - 触发方式：点击"新增用户"按钮
   - 展现形式：弹窗

2. **表单字段**

新增用户界面字段说明：
- **账号**：用户登录账号（必填）
- **姓名**：用户真实姓名（必填）
- **邮箱**：用户邮箱地址（必填）
- **手机号**：用户联系电话（必填）
- **密码**：初始登录密码，支持系统自动生成或手动输入
  - 系统生成密码：12位随机密码
  - 自定义密码选项
- **输入密码**：设置用户密码（必填）
- **确认密码**：再次输入密码进行确认（必填）

操作按钮：
- **取消**：关闭弹窗
- **保存**（绿色按钮）：提交创建用户

3. **字段校验规则**

| 字段名 | 类型 | 必填 | 校验规则 | 错误提示 |
|--------|------|------|----------|----------|
| 账号 | 文本框 | 是 | 4-20位字母数字 | 账号格式不正确 |
| 姓名 | 文本框 | 是 | 2-20位中文或字母 | 姓名格式不正确 |
| 邮箱 | 文本框 | 是 | 标准邮箱格式 | 邮箱格式不正确 |
| 手机号 | 文本框 | 是 | 11位手机号 | 手机号格式不正确 |
| 密码 | 密码框 | 是 | 8-20位 | 密码格式不正确 |
| 确认密码 | 密码框 | 是 | 与密码一致 | 两次密码不一致 |

4. **业务逻辑**
   - 邮箱全局唯一性验证
   - 密码需要加密存储
   - 用户创建后默认状态为"启用"
   - 系统自动生成12位随机密码
   - 记录创建时间

5. **操作流程**
   ```
   用户输入 → 前端校验 → 提交表单 → 后端验证 → 保存数据 → 提示成功
   ```

6. **成功提示**
   - 显示消息："用户创建成功"
   - 自动关闭弹窗
   - 刷新用户列表

7. **失败场景**
   - 邮箱已存在：提示"该邮箱已被使用，请更换"
   - 参数格式错误：提示具体错误信息
   - 系统异常：提示"系统繁忙，请稍后重试"

**业务规则**：
1. 邮箱全局唯一
2. 初始密码由系统生成（12位随机密码）
3. 用户创建后立即生效
4. 用户不能被删除（MVP阶段）
5. 所有账号统一拥有全部权限（MVP阶段）

**注意事项**：
- ⚠️ 密码必须加密存储，不能明文
- ⚠️ 邮箱需要验证唯一性
- 💡 后续版本支持用户删除功能
- 💡 后续版本支持权限控制

#### 操作：用户登录

**原型图**：
![登录界面](./原型图/用户管理/登录@1x.png)

**功能需求**：

1. **页面入口**
   - 地址：系统根路径 `/login`
   - 未登录访问其他页面自动跳转到登录页

2. **登录界面元素**

登录界面包含以下元素：
- **NovoGrowth品牌标识**：显示在页面顶部
- **账号输入框**：输入登录账号（占位符：请输入账号）
- **密码输入框**：输入登录密码（占位符：请输入密码），支持密码显示/隐藏切换
- **登录按钮**：大尺寸绿色按钮，点击提交登录
- **左侧插图**：展示办公场景的视觉插画

3. **登录流程**
   1. 用户输入账号和密码
   2. 点击"登录"按钮
   3. 系统验证账号存在性
   4. 验证账号状态（是否启用）
   5. 验证密码正确性
   6. 生成登录会话和Token
   7. 记录登录日志
   8. 跳转到主界面（应用管理应用）

4. **业务规则**

**输入验证**：
- 账号：必填，不能为空
- 密码：必填，不能为空

**登录安全**：
- 密码错误5次锁定账号30分钟
- 会话超时时间：24小时无操作自动退出
- 登录成功后生成Token，有效期24小时

**错误提示**：
- 账号不存在：提示"账号或密码错误"
- 密码错误：提示"账号或密码错误"
- 账号被禁用：提示"账号已被禁用，请联系管理员"
- 账号被锁定：提示"账号已被锁定，请30分钟后再试"

5. **操作流程**
   ```
   输入账号密码 → 点击登录 → 验证账号 → 验证密码 → 生成Token → 跳转首页
   ```

**注意事项**：
- ⚠️ 密码传输需要加密
- ⚠️ 防止暴力破解（5次锁定）
- 💡 后续版本支持验证码

4. **新增租户流程**

点击"保存"按钮后系统自动执行：

1. 验证租户信息（名称唯一性、邮箱格式等）
2. 在运营平台创建租户记录
3. 调用NovoGrowth API创建租户主账号
4. 自动授权所有应用模块（有效期：2099-12-31）
5. 推送授权配置到NovoGrowth
6. 更新租户状态为"已授权"
7. 发送邮件通知租户（含登录地址和初始密码）

5. **业务规则**

**新增租户规则**：
- 租户名称全局唯一
- 邮箱全局唯一（作为NovoGrowth主账号）
- 创建成功后自动授权所有应用
- 授权有效期：2099-12-31 23:59:59
- 授权立即推送到NovoGrowth（异步，支持重试）
- 授权成功后发送邮件通知租户

6. **操作流程**
   ```
   输入租户信息 → 前端校验 → 提交表单 → 后端验证 → 创建租户 
   → 创建NovoGrowth账号 → 自动授权 → 推送配置 → 提示成功
   ```

7. **成功提示**
   - 显示消息："租户创建成功，授权配置已推送"
   - 自动关闭弹窗
   - 刷新租户列表

8. **失败场景**
   - 租户名称已存在：提示"该租户名称已被使用，请更换"
   - 邮箱已存在：提示"该邮箱已被使用，请更换"
   - NovoGrowth账号创建失败：提示"NovoGrowth账号创建失败，请重试"
   - 授权推送失败：提示"授权配置推送失败，系统将自动重试"
   - 系统异常：提示"系统繁忙，请稍后重试"

**MVP简化说明**：
- ✅ 新增租户自动授权所有应用，无需手动授权
- ✅ 固定授权有效期：2099-12-31
- ❌ 不支持自定义授权范围（所有租户权限一致）
- ❌ 不支持授权到期提醒
- ❌ 不支持授权的修改和撤销
- ⏭️ V1.1：支持套餐体系和灵活授权

**注意事项**：

- ⚠️ 邮箱将作为NovoGrowth主账号
- ⚠️ 授权配置推送失败会自动重试（最多3次）
- 💡 建议：租户创建前与客户确认邮箱准确性
- 💡 后续版本支持租户状态管理（启用/停用）

## 7. 系统集成

### 7.1 与NovoGrowth的数据交互

运营平台与NovoGrowth平台需要进行数据同步，确保授权配置的一致性。

#### 7.1.1 数据交互清单

| 业务场景 | 数据流向 | 交互内容 | 触发时机 |
|---------|---------|---------|----------|
| 创建租户主账号 | 运营→NovoGrowth | 租户基本信息、管理员信息 | 创建租户时 |
| 同步账号状态 | 运营→NovoGrowth | 租户状态变更（停用、启用） | 状态发生变化时 |
| 同步授权配置 | 运营→NovoGrowth | 授权的模块、菜单、权限 | 新增租户时 |
| 删除租户数据 | 运营→NovoGrowth | 租户标识 | 删除租户时 |

#### 7.1.2 授权配置推送

运营平台需要将授权信息推送到NovoGrowth：

**推送内容**：
- 授权的所有应用模块
- 完整的菜单树结构
- 完整的权限列表
- 授权到期时间：2099-12-31 23:59:59

**推送时机**：
- 新增租户时自动推送（无需手动操作）

**推送结果**：
- NovoGrowth确认接收成功并缓存授权配置
- 租户即可登录使用

#### 7.1.3 数据一致性规则

**失败重试**：
- 数据同步失败时自动重试
- 最多重试3次
- 重试间隔：1秒、3秒、5秒

**异常告警**：
- 3次重试失败后发送告警
- 运营人员可手动重新推送

**补偿机制**：
- 提供手动同步功能
- 记录同步失败日志
