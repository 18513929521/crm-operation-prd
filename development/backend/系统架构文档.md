# CRM运营平台 - 系统架构文档

## 1. 概述

本文档描述了CRM运营平台的整体架构设计和核心技术栈。

### 1.1 产品层级

```
平台 (Platform)
  └── 应用 (Application)
      └── 功能 (Feature)
          └── 操作 (Operation)
```

**当前平台：** CRM运营平台（CRM Operation Platform）

**架构原则：** 一个应用对应一个微服务 + 一个数据库 + 一个微前端

## 2. 核心技术栈

### 2.1 开发语言与框架
- **Java 17**：核心开发语言，使用LTS长期支持版本
- **Spring Boot 3.2.x**：基础应用框架
- **Spring Cloud 2023.0.x (Leyton)**：微服务框架，提供分布式系统的基础设施支持
- **Spring Cloud Alibaba 2023.0.x**：阿里巴巴微服务解决方案，版本与Spring Cloud保持一致
- **Spring AI Alibaba 1.0.x**：阿里巴巴AI能力集成框架

### 2.2 服务治理与配置
- **Nacos 2.2.x**：服务注册与发现、配置管理中心

### 2.3 数据存储
- **MySQL 8.0.x**：关系型数据库，主要数据持久化存储
- **Redis 6.0.x**：分布式缓存，用于缓存热点数据、会话管理、分布式锁等

### 2.4 消息队列
- **RabbitMQ 3.13.x**：消息中间件（按需使用），用于异步处理、系统解耦、流量削峰

### 2.5 JSON处理
- **Fastjson2 2.0.x**：JSON序列化与反序列化，完全替代原本的Jackson

### 2.6 DevOps工具链
- **Jenkins 2.x**：持续集成/持续部署（CI/CD）
- **Docker 24.x**：容器化技术，应用打包与部署
- **Kubernetes (K8S) 1.28+**：容器编排平台，管理容器化应用

### 2.7 重要说明

> **Spring Boot 3.x 配置方式**
> - 不再使用 `bootstrap.yml`，统一使用 `application.yml`
> - 通过 `spring.config.import` 从 Nacos 导入配置
> - 配置详情请参考：[应用清单与部署配置.md](./微服务清单与部署配置.md)

**架构说明：**
- 每个应用（Application）独立部署为一个微服务
- 每个应用拥有独立的数据库，数据隔离
- 每个应用对应一个微前端模块

### 3.2 服务治理

- **服务注册与发现**：所有微服务通过Nacos进行注册，实现服务的自动发现
- **配置管理**：统一使用Nacos进行配置管理，支持配置动态更新
- **负载均衡**：Spring Cloud LoadBalancer实现客户端负载均衡
- **熔断降级**：Sentinel提供流量控制和熔断降级保护

### 3.3 数据层架构

- **主数据库**：MySQL 8.x，存储业务核心数据
- **缓存层**：Redis，提升系统性能，减轻数据库压力
  - 热点数据缓存
  - 分布式锁
  - 会话存储
  - 消息队列（List/Stream）

### 3.4 消息处理

- **RabbitMQ**（按需启用）
  - 异步任务处理
  - 系统解耦
  - 流量削峰

## 4. 平台应用清单

运营平台采用"一个应用一个微服务+数据库+微前端"的架构，包含以下核心应用：

| 应用名称 | 微服务名 | 数据库 | 微前端 | 端口 | 说明 |
|---------|---------|--------|--------|------|------|
| 网关 | crm-operation-gateway | - | - | 18100 | API网关，统一入口 |
| 系统管理 | crm-operation-system | crm_operation_system | system-management-ui | 18101 | 运营端管理、认证鉴权 |
| 租户管理 | crm-operation-tenant | crm_operation_tenant | tenant-management-ui | 18102 | 租户信息管理 |
| 应用管理 | crm-operation-application | crm_operation_application | application-management-ui | 18103 | 应用配置管理 |
| 角色权限模板 | crm-operation-role-template | crm_operation_role_template | role-template-management-ui | 18104 | 租户角色权限模板管理 |
| 基础设施 | crm-operation-infrastructure | crm_operation_infrastructure | infrastructure-ui | 18105 | 公共基础设施 |
| 工作流引擎 | crm-operation-workflow | crm_operation_workflow | workflow-engine-ui | 18106 | 工作流引擎 |

**架构特点：**
- 每个应用拥有独立的微服务、数据库和微前端模块
- 应用间通过API进行通信，数据完全隔离
- 统一使用Nacos进行服务注册与发现

详细的应用清单、端口分配、部署配置请参考：[微服务清单与部署配置.md](./微服务清单与部署配置.md)
