# CRM运营平台 - 代码规范

## 1. 概述

本文档定义了CRM运营平台的代码编写规范，所有开发人员必须严格遵守，以确保代码质量、可读性和可维护性。

### 1.1 产品层级

```
平台 (Platform)
  └── 应用 (Application)
      └── 功能 (Feature)
          └── 操作 (Operation)
```

**当前平台：** CRM运营平台（CRM Operation Platform）

**架构原则：** 一个应用对应一个微服务 + 一个数据库 + 一个微前端

## 2. 基础规范

### 2.1 总体原则

1. **遵循阿里巴巴Java开发手册**：作为基础规范
2. **保持代码简洁**：单个方法不超过50行，单个类不超过500行
3. **优先使用组合而非继承**
4. **面向接口编程**
5. **遵循SOLID原则**

### 2.2 开发工具配置

#### IDE设置
- **编码格式**：UTF-8
- **缩进**：4个空格（不使用Tab）
- **行宽限制**：120字符
- **自动格式化**：保存时自动格式化代码

#### 必备插件
- **Lombok**：简化JavaBean代码
- **CheckStyle**：代码风格检查
- **SonarLint**：代码质量检查
- **阿里巴巴Java规约插件**

## 7. 数据库规范

### 7.1 表命名规范

```sql
-- 表名：小写字母，下划线分隔，t_前缀
CREATE TABLE t_tenant (
    id BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '主键ID',
    tenant_name VARCHAR(50) NOT NULL COMMENT '租户名称',
    tenant_code VARCHAR(20) NOT NULL COMMENT '租户编码',
    status TINYINT NOT NULL DEFAULT 1 COMMENT '状态：1-启用，0-禁用',
    create_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    update_time DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    deleted TINYINT NOT NULL DEFAULT 0 COMMENT '逻辑删除：0-未删除，1-已删除',
    INDEX idx_tenant_code (tenant_code),
    INDEX idx_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='租户表';
```

### 7.2 字段规范

- **主键**：统一使用`id`，BIGINT类型，自增
- **逻辑删除**：统一使用`deleted`字段，TINYINT类型
- **创建时间**：统一使用`create_time`，DATETIME类型
- **更新时间**：统一使用`update_time`，DATETIME类型
- **状态字段**：使用`status`，TINYINT类型，定义清晰的状态值

### 7.3 索引规范

```sql
-- 单列索引
CREATE INDEX idx_tenant_code ON t_tenant(tenant_code);

-- 联合索引（最左匹配原则）
CREATE INDEX idx_status_create_time ON t_tenant(status, create_time);

-- 唯一索引
CREATE UNIQUE INDEX uk_tenant_code ON t_tenant(tenant_code);
```

### 8.2 统一响应格式

```java
@Data
public class Result<T> {
    private Integer code;
    private String message;
    private T data;
    private Long timestamp;
    
    // 成功响应：code=200
    public static <T> Result<T> success(T data) {
        Result<T> result = new Result<>();
        result.setCode(200);
        result.setMessage("success");
        result.setData(data);
        result.setTimestamp(System.currentTimeMillis());
        return result;
    }
    
    // 失败响应：code=500或其他错误码
    public static <T> Result<T> error(Integer code, String message) {
        Result<T> result = new Result<>();
        result.setCode(code);
        result.setMessage(message);
        result.setTimestamp(System.currentTimeMillis());
        return result;
    }
}
```

## 11. 性能优化规范

### 11.1 缓存使用

```java
@Service
public class TenantServiceImpl {
    
    @Autowired
    private RedisTemplate<String, Object> redisTemplate;
    
    private static final String CACHE_KEY_PREFIX = "tenant:";
    private static final long CACHE_EXPIRE = 3600L;
    
    public TenantVO getTenantById(Long id) {
        // 1. 先查缓存
        String cacheKey = CACHE_KEY_PREFIX + id;
        Tenant cached = (Tenant) redisTemplate.opsForValue().get(cacheKey);
        if (cached != null) {
            return convertToVO(cached);
        }
        
        // 2. 查询数据库
        Tenant tenant = tenantRepository.findById(id)
                .orElseThrow(() -> new BusinessException("租户不存在"));
        
        // 3. 写入缓存
        redisTemplate.opsForValue().set(cacheKey, tenant, CACHE_EXPIRE, TimeUnit.SECONDS);
        
        return convertToVO(tenant);
    }
}
```
