# CRM运营平台 - 前端开发流程规范

## 1. 概述

本文档定义了CRM运营平台前端的标准开发流程，确保代码质量、开发效率和团队协作的一致性。

### 1.1 技术要求

**开发环境：**
- **Node.js**: 16+ (LTS版本)
- **pnpm**: 8.0+
- **Git**: 2.30+
- **VSCode**: 最新版本（推荐）

### 1.2 适用范围

- 所有微前端应用的开发
- 功能特性的新增和修改
- Bug修复和性能优化

### 1.3 相关文档

- [系统架构文档](./系统架构文档.md)
- [代码规范](./代码规范.md)
- [微前端应用清单与部署配置](./微前端应用清单与部署配置.md)

## 2. 开发流程总览

```
项目初始化 → 环境搭建 → 功能开发 → 测试验证 → 代码提交 → 部署上线
```

```javascript
import './public-path';
import { createApp } from 'vue';
import { createRouter, createWebHistory } from 'vue-router';
import { createPinia } from 'pinia';
import ElementPlus from 'element-plus';
import 'element-plus/dist/index.css';
import App from './App.vue';
import routes from './router';

let app = null;
let router = null;
let history = null;

function render(props = {}) {
  const { container } = props;
  
  history = createWebHistory(window.__POWERED_BY_QIANKUN__ ? '/tenant' : '/');
  router = createRouter({
    history,
    routes
  });
  
  app = createApp(App);
  app.use(router);
  app.use(createPinia());
  app.use(ElementPlus);
  
  const containerElement = container 
    ? container.querySelector('#app') 
    : document.getElementById('app');
  app.mount(containerElement);
}

// 独立运行
if (!window.__POWERED_BY_QIANKUN__) {
  render();
}

// qiankun生命周期
export async function bootstrap() {
  console.log('[tenant-management] app bootstraped');
}

export async function mount(props) {
  console.log('[tenant-management] props from main app', props);
  render(props);
}

export async function unmount() {
  app?.unmount();
  app = null;
  router = null;
  history = null;
}
```

```
│   ├── components/            # 该模块专用组件
```

**目录命名规范：**

- 组件文件：PascalCase（如`TenantForm.vue`）

#### 5.2.2 组件分离和引用规范

**强制要求：弹框和组件必须独立文件，通过ref调用事件**

**❌ 错误示例（组件内嵌）：**
```vue

      <el-form :model="form">
        <!-- 表单内容 -->
      </el-form>
    </el-dialog>
  </div>
</template>
```


**弹框组件示例：**
```vue
<!-- components/TenantForm.vue -->
<template>
  <el-dialog
    v-model="dialogVisible"
    :title="dialogTitle"
    width="600px"
    @close="handleClose"
  >
    <el-form
      ref="formRef"
      :model="form"
      :rules="rules"
      label-width="100px"
    >
      <el-form-item label="租户名称" prop="name">
        <el-input v-model="form.name" placeholder="请输入租户名称" />
      </el-form-item>
      <el-form-item label="租户编码" prop="code">
        <el-input v-model="form.code" placeholder="请输入租户编码" />
      </el-form-item>
    </el-form>
    
    <template #footer>
      <el-button @click="handleClose">取消</el-button>
      <el-button type="primary" @click="handleSubmit" :loading="loading">
        确定
      </el-button>
    </template>
  </el-dialog>
</template>

<script setup>
import { ref, reactive, computed } from 'vue';
import { ElMessage } from 'element-plus';

// 定义事件
const emit = defineEmits(['success', 'close']);

// 响应式数据
const dialogVisible = ref(false);
const loading = ref(false);
const formRef = ref();
const mode = ref('add'); // add | edit
const editData = ref(null);

// 表单数据
const form = reactive({
  name: '',
  code: '',
  status: 1
});

// 表单验证规则
const rules = {
  name: [
    { required: true, message: '请输入租户名称', trigger: 'blur' }
  ],
  code: [
    { required: true, message: '请输入租户编码', trigger: 'blur' }
  ]
};

// 计算属性
const dialogTitle = computed(() => {
  return mode.value === 'add' ? '新增租户' : '编辑租户';
});

// 打开弹框
const open = (type, data = null) => {
  mode.value = type;
  editData.value = data;
  
  if (type === 'edit' && data) {
    // 编辑模式，填充数据
    Object.assign(form, data);
  } else {
    // 新增模式，重置表单
    resetForm();
  }
  
  dialogVisible.value = true;
};

// 关闭弹框
const handleClose = () => {
  dialogVisible.value = false;
  resetForm();
  emit('close');
};

// 重置表单
const resetForm = () => {
  Object.assign(form, {
    name: '',
    code: '',
    status: 1
  });
  formRef.value?.clearValidate();
};

// 提交表单
const handleSubmit = async () => {
  if (!formRef.value) return;
  
  try {
    const valid = await formRef.value.validate();
    if (!valid) return;
    
    loading.value = true;
    
    // TODO: 调用API
    if (mode.value === 'add') {
      // await tenantApi.create(form);
    } else {
      // await tenantApi.update(editData.value.id, form);
    }
    
    ElMessage.success(mode.value === 'add' ? '新增成功' : '编辑成功');
    emit('success');
    handleClose();
    
  } catch (error) {
    console.error('提交失败', error);
  } finally {
    loading.value = false;
  }
};

// 暴露方法给父组件
defineExpose({
  open,
  close: handleClose
});
</script>
```

**父组件调用子组件方法：**
```vue

<script setup>
import { ref } from 'vue';

const childRef = ref();

const handleParentAction = () => {
  childRef.value.openDialog();

<template>
  <ChildComponent ref="childRef" @event="handleChildEvent" />
</template>
```

```vue
import { ref } from 'vue';

const visible = ref(false);
```

#### 5.3.2 Store状态层

```javascript
// stores/tenant-store.js
import { defineStore } from 'pinia';
import { ref, computed } from 'vue';
import { tenantApi } from '@/api';

export const useTenantStore = defineStore('tenant', () => {
  const loading = ref(false);
  const tenantList = ref([]);
  const currentTenant = ref(null);
  const pagination = ref({
    page: 1,
    size: 10,
    total: 0
  });
  
  // 获取租户列表
  const fetchTenantList = async (params) => {
    loading.value = true;
    try {
      const data = await tenantApi.getList({
        page: pagination.value.page,
        size: pagination.value.size,
        ...params
      });
      tenantList.value = data.list;
      pagination.value.total = data.total;
      return data;
    } catch (error) {
      console.error('获取租户列表失败', error);
      throw error;
    } finally {
      loading.value = false;
    }
  };
  
  // 创建租户
  const createTenant = async (data) => {
    loading.value = true;
    try {
      await tenantApi.create(data);
      await fetchTenantList();
    } catch (error) {
      throw error;
    } finally {
      loading.value = false;
    }
  };
  
  return {
    loading,
    tenantList,
    currentTenant,
    pagination,
    fetchTenantList,
    createTenant
  };
});
```

### 12.1 微应用无法加载

**原因：**
- 端口配置错误
- CORS跨域问题
- qiankun配置错误

**解决方案：**
- 检查Vite配置中的端口和CORS设置
- 检查主应用中的微应用注册配置
- 查看浏览器控制台错误信息

### 12.2 路由冲突

**原因：**
- 主应用和微应用路由冲突
- 路由base配置错误

**解决方案：**
- 确保微应用路由有正确的base前缀
- 使用`window.__POWERED_BY_QIANKUN__`判断运行环境
- 检查路由配置是否正确

### 12.3 样式污染

**原因：**
- CSS全局样式污染
- Element Plus样式冲突

**解决方案：**
- 使用`scoped`样式
- 使用CSS Modules
- 启用qiankun的样式隔离
- 为每个应用添加命名空间前缀

### 12.4 状态管理混乱

**原因：**
- Store设计不合理
- 状态更新不规范

**解决方案：**
- 合理拆分Store
- 使用Pinia的模块化设计
- 遵循单向数据流原则
- 使用Composition API风格的Store
