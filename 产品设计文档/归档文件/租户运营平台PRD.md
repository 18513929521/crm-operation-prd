## 2. 引言

### 2.1 产品愿景
打造一款专业、高效的SaaS租户运营平台，为平台运营团队提供全方位的租户管理、订阅计费、监控分析、客服支持等能力，提升运营效率和用户体验，助力SaaS业务健康增长。

### 2.2 背景与目标
- **背景**：SaaS业务快速发展，租户数量激增，传统的人工运营方式效率低下，亟需系统化的运营管理平台。
- **目标**：
  - 实现租户全生命周期自动化管理，降低运营成本30%+
  - 提供精细化订阅计费能力，支持多种计费模式
  - 实时监控租户健康度，降低流失率20%+
  - 提供高效的客服支持工具，提升客户满意度

### 2.3 目标用户
- **主要用户**：SaaS平台运营团队（运营经理、客户成功、技术支持）
- **次要用户**：财务团队（计费对账）、管理层（数据分析与决策）
- **用户特征**：需要快速响应租户需求、重视数据驱动决策、追求运营自动化

## 4. 整体解决方案

租户运营平台以**租户生命周期管理**为核心，覆盖租户从**注册、试用、订阅、续费、扩容、流失**全流程，提供**订阅计费、配额管理、监控分析、客服支持、运营账号管理、应用授权管理**等能力，实现SaaS业务的精细化运营。

针对NovoGrowth智能增长平台，提供**业务需求分析、Leads管理、CRM管理、系统管理**四大模块的灵活授权，以及**工作流定制、页面布局、字段自定义**等定制化能力的权限管理。

### 4.1 核心价值
- **全流程管理**：从租户注册到流失挽回，全生命周期闭环管理
- **自动化能力**：订阅到期提醒、配额预警、健康度监控等自动化任务
- **数据驱动**：实时监控关键指标（MRR、流失率、Leads转化率、CRM成单率等），支持决策
- **灵活计费**：支持多种计费模式（按量、按时间、分级等），支持按线索数、用户数等业务指标计费
- **细粒度授权**：支持模块级、功能级的灵活授权，满足不同租户需求
- **定制化管控**：工作流、页面、字段等定制能力的权限管理和限制

   - 租户注册时创建账号并推送初始授权
   - 订阅变更时推送新的授权和配额配置
   - 账号状态变化时实时同步

2. **NovoGrowth→运营平台**（定时回传）：
   - 每5分钟回传配额使用数据
   - 每日回传活跃度和使用统计
   - 实时推送Webhook事件（异常告警等）

3. **授权验证**（NovoGrowth本地）：
   - NovoGrowth缓存授权配置到Redis
   - 用户操作时实时校验权限和配额
   - 未授权功能显示升级提示

## 5. 详细功能需求

### 5.1 租户生命周期管理

#### 5.1.1 租户注册与激活
- **功能描述**：支持租户自助注册和激活，并在NovoGrowth平台创建租户空间
- **功能要点**：
  - 注册表单（企业名称、联系人、邮箱、手机等）
  - 邮箱/手机验证
  - 租户唯一标识（Tenant ID）自动生成
  - 初始化租户数据库/资源
  - **为租户在NovoGrowth平台创建主账号**：
    - 自动生成主账号（邮箱作为用户名）
    - 生成初始密码（随机强密码）
    - 通过集成API同步创建到NovoGrowth系统
    - 在NovoGrowth侧初始化租户独立数据空间
    - 根据订阅套餐推送初始授权配置到NovoGrowth
  - 发送账号激活邮件（包含NovoGrowth登录地址和初始密码）
  - 注册来源追踪（广告、推荐等）
- **业务规则**：
  - 邮箱/手机需唯一性校验
  - NovoGrowth主账号创建失败需回滚运营平台租户创建（保证数据一致性）
  - 注册成功后自动发送欢迎邮件和账号信息
  - 主账号首次登录NovoGrowth需强制修改密码
  - 支持邀请注册（推荐奖励）
  - 账号创建状态可追踪（待创建/创建中/已创建/创建失败）
- **验收标准**：
  - 注册流程<3步完成
  - 注册成功率≥95%
  - NovoGrowth账号创建成功率≥99%
  - 账号创建失败自动回滚成功率100%
  - 激活邮件送达率≥98%

#### 5.1.2 试用管理
- **功能描述**：支持租户免费试用，体验核心功能
- **功能要点**：
  - 试用期配置（如14天、30天）
  - 试用套餐功能限制（如用户数≤5）
  - 试用到期提醒（邮件/站内信）
  - 试用转正流程
- **业务规则**：
  - 试用期间数据保留，转正后继续使用
  - 试用到期自动提醒（提前3天、1天、到期当天）
  - **NovoGrowth账号处理规则**：
    - 试用期内：NovoGrowth账号正常使用，显示试用标识和剩余天数
    - 试用到期未转正：
      - 即时同步账号状态到NovoGrowth（设置为"试用过期"状态）
      - NovoGrowth账号设为"只读"模式（仅可查看数据，不可编辑/新增）
      - 页面显著位置提示"试用已到期，请联系管理员升级"
      - 数据保留30天
    - 试用转正：
      - 立即解除NovoGrowth账号限制
      - 同步推送正式套餐的授权配置
      - 账号状态变更为"正式"
  - 试用到期后自动降级或锁定账户
- **验收标准**：
  - 试用到期提醒准时率100%
  - 账号状态同步到NovoGrowth时延<1分钟
  - 试用转正率≥20%

#### 5.1.3 订阅与续费
- **功能描述**：支持租户订阅服务和自动续费
- **功能要点**：
  - 套餐选择（基础版/专业版/企业版等）
  - 订阅周期（月付/年付）
  - 在线支付（对接支付网关）
  - 自动续费设置
  - 续费提醒（到期前7天、3天、1天）
- **业务规则**：
  - 订阅成功后立即生效
  - **NovoGrowth授权同步**：
    - 订阅成功后立即推送套餐授权配置到NovoGrowth
    - NovoGrowth实时更新租户可用功能和配额
    - 授权同步失败自动重试，成功后确认订单完成
  - **续费失败处理**：
  - 自动续费失败需人工跟进
    - 宽限期7天（期间NovoGrowth账号正常使用但显示续费提醒横幅）
    - 宽限期结束后：
      - NovoGrowth账号自动锁定（只读模式）
      - 同步账号状态为"订阅过期"
      - 数据保留30天，超期后归档
    - 宽限期内完成续费立即解锁
  - 支持中途升级/降级套餐（需同步新授权配置到NovoGrowth）
- **验收标准**：
  - 支付成功率≥95%
  - 授权配置同步时延<1分钟
  - 续费提醒准时率100%
  - 自动续费成功率≥90%
  - 账号锁定/解锁同步准确率100%

#### 5.1.4 扩容与升级
- **功能描述**：支持租户按需扩容和套餐升级
- **功能要点**：
  - 用户数/存储空间等资源扩容
  - 套餐升级（基础版→专业版）
  - 差价计算与补缴
  - 升级后权限即时生效
- **业务规则**：
  - 扩容/升级支持立即生效或下周期生效
  - 差价按剩余周期比例计算
  - **升级授权同步**：
    - 支付成功后立即推送新配额和权限到NovoGrowth
    - NovoGrowth实时解锁新功能模块
    - 配额限制实时更新（如用户数从5→20）
    - 原有数据和配置完整保留
  - **降级处理**：
  - 降级仅支持到期后变更
    - 降级生效时同步更新NovoGrowth授权
    - 超出新配额的数据处理：
      - 已有数据保留（只读），不可新增
      - 提示用户清理或升级套餐
      - 已创建的自定义工作流保留但不可新增
- **验收标准**：
  - 扩容/升级操作<5分钟生效
  - 授权同步时延<1分钟
  - 差价计算准确率100%
  - 降级数据处理准确率100%

#### 5.1.5 流失预警与挽回
- **功能描述**：识别流失风险租户，主动挽回
- **功能要点**：
  - 流失预警模型（基于活跃度、使用频率、健康度等）
  - 自动标记高风险租户
  - 挽回策略（优惠券、客户成功跟进等）
  - 流失原因调研
- **业务规则**：
  - 高风险租户自动推送给客户成功团队
  - 挽回策略效果可追踪
- **验收标准**：
  - 流失预警准确率≥75%
  - 挽回成功率≥30%

#### 5.1.6 租户归档与删除
- **功能描述**：支持租户注销和数据归档
- **功能要点**：
  - 租户主动注销申请
  - 数据备份与归档（保留30天）
  - 资源释放
  - 注销原因收集
- **业务规则**：
  - 注销需二次确认
  - **NovoGrowth账号处理**：
    - 注销申请提交后：
      - 立即冻结NovoGrowth账号（禁止登录）
      - 在运营平台和NovoGrowth双侧数据备份
      - 账号状态变更为"已注销"
    - 归档期内（30天）：
      - 支持数据恢复（需租户重新申请）
      - 恢复时同步激活NovoGrowth账号
      - 数据和配置完整恢复
    - 归档期后：
      - 运营平台和NovoGrowth同步永久删除租户数据
      - 释放Tenant ID和相关资源
      - 删除操作不可逆
  - 归档期内支持数据恢复
  - 归档期后数据永久删除
- **验收标准**：
  - 数据备份成功率100%（双侧备份）
  - 账号冻结同步时延<1分钟
  - 数据恢复成功率≥99%
  - 资源释放及时率100%

### 5.2 订阅与计费管理

#### 5.2.1 套餐管理
- **功能描述**：配置和管理多种订阅套餐
- **功能要点**：
  - 套餐定义（名称、价格、功能、配额等）
  - **功能模块包含配置**：
    - 业务需求分析（自然语言转化、用户画像）
    - Leads管理（大库、私有库、触达工具）
    - CRM管理（客户池、商机管理、渠道管理、成单管理）
    - 系统管理（用户、角色、权限、数据字典等）
  - **定制化能力配置**：
    - 工作流定制权限（是否允许自定义销售流程）
    - 页面布局定制权限（是否允许自定义页面布局）
    - 字段自定义权限（是否允许自定义字段）
    - 审批流定制权限
  - 多种计费模式：
    - 按时间（月/季/年）
    - 按量（API调用次数、线索数量、存储空间等）
    - 分级定价（用户数分档、线索数分档）
  - 套餐版本管理（支持新老套餐并存）
  - 套餐可见性控制（公开/私有/定向）
- **业务规则**：
  - 套餐变更需版本控制，老用户不受影响
  - 套餐价格调整需提前通知
  - 定制化能力与套餐等级关联（如：基础版不支持工作流定制，企业版支持）
- **验收标准**：
  - 支持≥5种计费模式组合
  - 套餐配置灵活，无需开发介入
  - 功能模块粒度可精细控制

#### 5.2.2 订单管理
- **功能描述**：管理租户订阅订单
- **功能要点**：
  - 订单创建（新购/续费/升级）
  - 订单状态跟踪（待支付/已支付/已取消）
  - 订单详情（套餐、金额、周期、优惠等）
  - 订单导出与统计
- **业务规则**：
  - 订单支付超时自动取消（默认30分钟）

## 7. 系统集成

### 7.1 NovoGrowth系统集成（核心）

租户运营平台与NovoGrowth平台通过API实现深度集成，确保租户管理、授权配置、配额控制的实时同步和一致性。

#### 7.1.1 账号同步集成

**租户主账号创建**
- **API接口**：`POST /api/v1/tenant/create`
- **请求参数**：
  ```json
  {
    "tenant_id": "租户唯一标识",
    "company_name": "企业名称",
    "admin_email": "管理员邮箱",
    "admin_phone": "管理员手机",
    "initial_password": "初始密码（加密）",
    "subscription_plan": "订阅套餐代码"
  }
  ```
- **返回结果**：
  ```json
  {
    "success": true,
    "account_id": "主账号ID",
    "login_url": "NovoGrowth登录地址"
  }
  ```
- **业务逻辑**：
  - NovoGrowth接收请求后创建租户主账号
  - 初始化租户独立数据空间（基于租户ID隔离）
  - 返回创建结果和登录地址
  - 创建失败返回错误信息（如邮箱已存在）

**账号状态同步**
- **API接口**：`PUT /api/v1/tenant/{tenant_id}/status`
- **请求参数**：
  ```json
  {
    "status": "active|trial_expired|subscription_expired|frozen|deleted",
    "effective_time": "生效时间戳"
  }
  ```
- **支持的状态**：
  - `active`: 正常使用
  - `trial_expired`: 试用到期（只读模式）
  - `subscription_expired`: 订阅过期（禁止登录）
  - `frozen`: 冻结（注销申请后）
  - `deleted`: 已删除
- **业务逻辑**：
  - NovoGrowth根据状态实时更新账号权限
  - 状态变更后用户下次操作时立即生效
  - 支持定时生效（如续费宽限期结束）

**单点登录（SSO）**
- **协议**：OAuth 2.0
- **场景**：运营人员从运营平台跳转到租户NovoGrowth空间
- **流程**：
  1. 运营平台生成临时授权码（有效期5分钟）
  2. 携带授权码跳转到NovoGrowth
  3. NovoGrowth验证授权码并创建会话
  4. 运营人员以租户视角查看系统
- **权限限制**：
  - 仅查看权限，不可修改租户数据
  - 访问时长限制（1小时自动退出）
  - 所有操作记录审计日志

#### 7.1.2 授权配置同步集成

**授权配置推送**
- **API接口**：`POST /api/v1/tenant/{tenant_id}/authorization/sync`
- **请求参数**：
  ```json
  {
    "modules": [
      {
        "module_id": "模块ID（如leads_management）",
        "enabled": true,
        "features": ["feature_1", "feature_2"],
        "sub_modules": [
          {
            "sub_module_id": "子模块ID（如ai_search）",
            "enabled": true
          }
        ]
      }
    ],
    "customization": {
      "workflow_enabled": true,
      "workflow_limit": 10,
      "page_layout_enabled": true,
      "page_layout_limit": 20,
      "custom_field_enabled": true,
      "custom_field_limit": 50
    },
    "quotas": {
      "max_users": 20,
      "max_leads": 10000,
      "max_customers": 5000,
      "max_storage_gb": 100
    },
    "expire_time": "授权到期时间戳（null表示永久）"
  }
  ```
- **返回结果**：
  ```json
  {
    "success": true,
    "synced_at": "同步时间戳",
    "cache_updated": true
  }
  ```
- **业务逻辑**：
  - NovoGrowth接收授权配置并更新到Redis缓存
  - 清除旧的授权缓存，立即生效
  - 用户下次访问时根据新授权展示菜单和功能

**授权验证接口**
- **API接口**：`GET /api/v1/tenant/{tenant_id}/authorization/validate`
- **用途**：运营平台定期验证授权同步状态
- **返回结果**：
  ```json
  {
    "tenant_id": "租户ID",
    "authorization_version": "授权配置版本号",
    "last_synced_at": "最后同步时间",
    "status": "active|expired|not_found"
  }
  ```

#### 7.1.3 使用数据回传集成

**配额使用数据回传**
- **API接口**：运营平台提供 `POST /api/v1/usage/report`
- **NovoGrowth推送频率**：每5分钟
- **推送内容**：
  ```json
  {
    "tenant_id": "租户ID",
    "timestamp": "统计时间戳",
    "quotas": {
      "users": {"used": 15, "limit": 20},

      "custom_workflows": {"used": 8, "limit": 10}
    }
  ```

- **业务逻辑**：
  - 运营平台接收数据并存储
  - 计算配额使用率
  - 触发预警（使用率≥80%）

**活跃度数据回传**
- **推送频率**：每日凌晨（批量）
- **推送内容**：
  ```json
  {
    "tenant_id": "租户ID",
    "date": "统计日期",
  ```

  - 租户健康度评估
  - 使用情况分析
  - 流失预警

**Webhook事件通知**
- **运营平台提供Webhook接口**：`POST /api/v1/webhook/events`
- **NovoGrowth推送的事件**：
  - 配额预警：配额使用率达到阈值
  - 异常行为：大量操作失败、异常登录等
  - 功能使用：首次使用某个高级功能
- **事件格式**：
  ```json
  {
    "event_type": "quota_warning|abnormal_behavior|feature_used",
    "tenant_id": "租户ID",
    "timestamp": "事件时间戳",
    "data": {
      // 事件相关数据
    }
  }
  ```

#### 7.1.4 配额控制集成

**配额校验流程**（NovoGrowth侧）
1. 用户执行操作（如创建Leads）
2. NovoGrowth从缓存读取配额配置
3. 查询当前使用量（从数据库统计）
4. 判断是否超额：
   - 未超额：允许操作，使用量+1
   - 已超额：阻止操作，返回错误提示
5. 定时同步使用量到运营平台

**配额刷新机制**
- 运营平台调整配额后推送到NovoGrowth
- NovoGrowth清除配额缓存并重新加载
- 用户下次操作时使用新配额限制

**超额宽限期处理**
- 运营平台配置宽限期（如允许超额5%）
- NovoGrowth校验时考虑宽限比例
- 超出宽限期后严格限制

#### 7.1.5 数据隔离与安全

**租户数据隔离**
- **NovoGrowth侧**：
  - 基于tenant_id进行数据隔离
  - 所有数据表包含tenant_id字段
  - 数据库查询强制带租户过滤条件
  - 缓存key包含tenant_id前缀
- **运营平台侧**：
  - 无法直接访问NovoGrowth租户业务数据
  - 仅接收统计数据和元数据
  - 敏感数据（客户信息、商机详情）不回传

**API安全**
- **认证机制**：
  - 基于API Key + Secret签名认证
  - 每个请求包含签名和时间戳（防重放攻击）
  - API Key定期轮换
- **传输安全**：
  - 所有API调用使用HTTPS
  - 敏感数据（如密码）加密传输
- **限流保护**：
  - API调用频率限制（如100次/分钟）
  - 异常请求自动熔断

#### 7.1.6 容错与一致性保障

**同步失败处理**
- **重试机制**：
  - 自动重试3次（间隔1/3/5分钟）
  - 重试失败后推送告警
  - 运营人员可手动触发重新同步
- **消息队列保障**：
  - 关键操作（授权变更、配额调整）使用消息队列
  - 确保消息不丢失
  - 支持消息持久化和死信队列

**数据一致性**
- **关键操作事务保障**：
  - 租户创建：运营平台+NovoGrowth账号创建事务
  - 失败回滚：NovoGrowth创建失败自动删除运营平台租户
- **定期数据对账**：
  - 每日对账租户列表、授权配置、配额配置
  - 发现不一致自动告警
  - 运营人员人工介入修复

**系统独立性**
- 运营平台和NovoGrowth可独立部署和升级
- 任一方故障不影响对方基本运行
- API接口版本兼容策略（向下兼容）
