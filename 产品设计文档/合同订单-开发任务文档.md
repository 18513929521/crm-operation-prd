## 二、主链路（本期必须打通）

```
合同「存草稿」     → 仅合同草稿，不生成订单
合同「正式保存」   → 合同锁定（生效）
                   → 每个服务项自动生成 1 条「订单草稿」

订单「草稿编辑」   → 补数据需求 / 交付配置
订单「正式保存」   → 订单锁定（待执行）
                   ├─ 寻迹：本期不建任务（预留规则）
                   └─ 推送：本期生成任务接口可预留/占位，任务 UI 不做
```

运维级联（暂停 / 继续 / 关闭 → 任务）：本期只做**订单侧状态变更**；任务侧级联因任务未做可只留 Service 注释或空实现。

## 五、后端任务（crm-operation-homework-job）

> 现状：无合同/订单实体；作业里的 `orderType` 是「目标圈选方式」，**不是**商业订单。本期新建合同/订单域，**不改动**现有 homework API。

### 5.1 表结构（建议）

| 表 | 说明 |
| --- | --- |
| `t_contract` | 合同主表（基础+商务+状态+ToB 维度+附件） |
| `t_contract_service` | 合同服务项（一对多） |
| `t_order` | 订单主表（关联合同/服务项；继承字段 + 可编辑配置） |
| `t_order_condition` | 订单筛选条件行（公司/联系人条件，可选 JSON 存主表） |
| `t_order_company` | 指定名单公司行（复用作业名单思路） |

过期推进：定时任务或查询时按结束日期计算（可先查询时判定，后补 Job）。

### 5.2 API 建议

**合同** `/v1/contracts`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/page` | 分页列表（仅 To B） |
| GET | `/{id}` | 详情（含服务项） |
| POST | `/draft` | 存草稿 |
| POST | `/` 或 `/publish` | 正式保存（锁定 + 生成订单草稿） |
| PUT | `/draft/{id}` | 草稿更新 |
| DELETE | `/{id}` | 仅草稿可删 |

**订单** `/v1/orders`

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/page` | 分页列表（支持 contractId 筛选） |
| GET | `/{id}` | 详情 |
| PUT | `/draft/{id}` | 草稿保存（步骤内暂存可同接口） |
| POST | `/{id}/publish` | 正式保存 |
| POST | `/{id}/pause` | 暂停 |
| POST | `/{id}/resume` | 继续 |
| POST | `/{id}/close` | 关闭 |
| POST | `/import-company` | 指定名单 Excel 解析（返回条数 + 预览） |

附件上传：复用现有 Infrastructure Feign 文件上传。

### 5.3 后端任务拆分

| ID | 任务 | 说明 |
| --- | --- | --- |
| BE-01 | DDL + PO/Entity/Enum | 合同/服务项/订单表与状态枚举 |
| BE-02 | 合同 CRUD + 草稿/正式保存 | 正式保存事务内生成订单草稿 |
| BE-03 | 合同分页/详情/删除 | 状态过滤、仅草稿可删 |
| BE-04 | 订单分页/详情 | 含交付进度字段 |
| BE-05 | 订单草稿更新 | 目标范围、条件、名单、交付配置 |
| BE-06 | 名单 Excel 解析 | 统计有效行数 N |
| BE-07 | 订单正式保存 | 锁定 + 状态流转；推送建任务占位 |
| BE-08 | 暂停/继续/关闭 | 仅待执行/执行中可暂停；继续恢复暂停前状态；关闭仅已暂停 |
| BE-09 | 合同过期判定 | **查询时判定**：列表/详情若生效且已过结束日期，按过期返回（可顺带回写库） |

## 九、已拍板规则（补充）

1. **后端**：落 `crm-operation-homework-job` 同库同服务。  
2. **订单暂停 / 继续**：  
   - 可暂停：**待执行**、**执行中**  
   - 暂停时写入 `status_before_pause`（或等价字段）  
   - **继续**：恢复为暂停前状态（不是固定回到执行中）  
   - 关闭：仅「已暂停」可关
