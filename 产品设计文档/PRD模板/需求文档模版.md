#### 操作：创建用户

**原型图**：
![创建用户页面](./images/create-user.png)

**功能需求**：

1. **页面入口**
   - 位置：用户管理页面
   - 触发方式：点击"新建用户"按钮
   - 展现形式：弹窗/新页面

2. **表单字段**

| 字段名 | 类型 | 必填 | 校验规则 | 错误提示 |
|--------|------|------|----------|----------|
| 用户名 | 文本框 | 是 | 4-20位字母数字下划线 | 用户名格式不正确 |
| 密码 | 密码框 | 是 | 8-20位，包含大小写字母和数字 | 密码强度不足 |
| 确认密码 | 密码框 | 是 | 与密码一致 | 两次密码不一致 |
| 真实姓名 | 文本框 | 是 | 2-20位中文或字母 | 姓名格式不正确 |
| 邮箱 | 文本框 | 否 | 标准邮箱格式 | 邮箱格式不正确 |
| 手机号 | 文本框 | 否 | 11位手机号 | 手机号格式不正确 |

3. **业务逻辑**
   - 用户名唯一性验证
   - 密码需要加密存储
   - 默认状态为"启用"
   - 记录创建人和创建时间

4. **操作流程**
   ```
   用户输入 → 前端校验 → 提交表单 → 后端验证 → 保存数据 → 提示成功
   ```

5. **成功提示**
   - 显示消息："用户创建成功"
   - 自动关闭弹窗
   - 刷新用户列表

6. **失败场景**
   - 用户名已存在：提示"该用户名已被使用，请更换"
   - 参数格式错误：提示具体错误信息
   - 系统异常：提示"系统繁忙，请稍后重试"

**注意事项**：
- ⚠️ 密码必须加密存储，不能明文
- ⚠️ 用户名创建后不能修改
- ⚠️ 邮箱和手机号需要验证唯一性
- 💡 建议：提供批量导入功能（后续版本）

**其他说明**：
- 创建用户后自动发送欢迎邮件（可选）
- 支持自定义用户初始权限（可选）

---

#### 操作：查询用户

**原型图**：
![用户列表页面](./images/user-list.png)

**功能需求**：

1. **查询方式**
   - 按ID查询（单个）
   - 列表查询（分页）
   - 高级搜索（多条件）

2. **列表展示**

| 显示字段 | 字段说明 | 操作 |
|----------|----------|------|
| 用户名 | 登录用户名 | 支持排序 |
| 真实姓名 | 用户真实姓名 | 支持搜索 |
| 邮箱 | 用户邮箱 | - |
| 状态 | 启用/禁用 | 支持筛选 |
| 创建时间 | 用户创建时间 | 支持排序 |
| 操作 | 编辑/删除/禁用 | - |

3. **搜索条件**
   - 用户名（模糊搜索）
   - 真实姓名（模糊搜索）
   - 状态（下拉选择）
   - 创建时间范围（日期选择）

4. **分页配置**
   - 默认每页20条
   - 支持10/20/50/100条切换
   - 显示总记录数

**注意事项**：
- ⚠️ 密码字段不返回给前端
- ⚠️ 逻辑删除的用户不显示
- 💡 支持导出Excel（后续版本）

#### 操作：更新用户

**原型图**：
![编辑用户页面](./images/edit-user.png)

**功能需求**：

1. **可编辑字段**
   - 真实姓名
   - 邮箱
   - 手机号
   - 密码（单独修改）
   - 状态

   - 创建时间

   - 显示最后更新时间

#### 操作：删除用户

**功能需求**：

1. **删除方式**
   - 逻辑删除（软删除）
   - 标记deleted字段为1

2. **删除限制**
   - 不能删除自己
   - 不能删除超级管理员
   - 需要二次确认

3. **关联处理**
   - 清除用户的登录会话
   - 解除用户的角色关联
   - 保留用户的历史操作记录

**注意事项**：
- ⚠️ 删除操作不可恢复（逻辑删除）
- ⚠️ 需要记录删除操作日志
- 💡 建议：提供回收站功能（后续版本）

**业务规则**：
1. 用户名全局唯一
2. 密码必须加密存储
3. 邮箱和手机号可选但建议填写
4. 新用户默认状态为"启用"
5. 自动记录创建人和创建时间

**注意事项**：
- ⚠️ 密码传输需要安全加密
- ⚠️ 防止恶意批量注册
- ⚠️ 用户名不能包含特殊字符
- 💡 提示用户设置强密码

**其他说明**：
- 创建成功后可选择立即分配角色
- 支持批量创建（后续版本）
- 支持从Excel导入（后续版本）

## 7. 交互设计要点

### 7.1 页面布局

- 列表页：顶部搜索栏 + 操作按钮 + 数据表格 + 分页组件
- 创建/编辑页：表单布局，必填项标红星
- 详情页：只读展示，可点击编辑按钮

### 7.2 交互规范

**按钮样式**：
- 主要操作：蓝色按钮（如"保存"、"确定"）
- 次要操作：灰色按钮（如"取消"、"返回"）
- 危险操作：红色按钮（如"删除"）

**提示信息**：
- 成功操作：绿色提示，3秒自动消失
- 错误信息：红色提示，需手动关闭
- 警告信息：黄色提示，需确认

**加载状态**：
- 列表加载：显示骨架屏
- 按钮操作：按钮置灰并显示loading
- 数据提交：全屏loading遮罩

### 7.3 响应式设计

- PC端：表格展示，支持多列排序
- 移动端：卡片展示，简化操作流程
- 最小宽度：320px（移动端）
